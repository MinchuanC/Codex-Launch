## Corrections caught by verification

- Scaling the central SVG light could displace it outside the assembly. A failing optical-center/bounds regression led to using a small HTML light inside the same assembly while keeping the original SVG vanes.
- Generic native hide/replace paths left deferred launch activation pending. Shared cleanup now cancels that focus intent; a normal Skip/handoff separately preserves the user-requested background launch.
- Selecting a different target during a pending launch could leave the old generation valid. Request identity now belongs to the launched target, independently of the currently selected target.
- A queued old WebKit completion could close a new opening. Automatic completion now carries and validates a native presentation token.
- Disposing a controller could accept delayed opening completion. Disposal invalidates the outstanding generation.
- A nonactivating panel could pause an opacity-from-zero entrance and leave the deck blank. Panel entrance is skipped until WebKit reports the page visible and otherwise animates only position, so controls remain visible if frames are throttled. The native smoke check samples actual pixels and was observed failing before this fix and passing afterward.

## Explicit gaps

- No cold restart of the user's ChatGPT/Codex host, physical keyboard/mouse walkthrough of every path, VoiceOver session, extra-monitor disconnect, or exhaustive fullscreen/Spaces/lock/sleep/session-switch matrix. Public lifecycle handling and geometry/state tests exist; these are not substitutes for that hardware matrix.
- No fixed-refresh benchmark, long-duration idle CPU measurement, battery measurement, notarization, or other-Mac distribution testing.
- No network-disconnection experiment. Runtime resource bundling, a restrictive `connect-src 'none'` CSP and denied external navigation were checked; no remote runtime assets are referenced.
- No native screen recording. Screenshots are of the app's own rendered views; a browser movie export was abandoned after its automation call stalled, without treating it as verification.
- App activation identifies the combined ChatGPT app, not the internal Codex section. The tab can also appear while another section of that app is in use. No conversation state is read or inferred.

The app is a usable local build with the tested behavior above, not a claim that every manual acceptance scenario has been verified. Source is kept on the local feature branch; no merge, push, system startup installation or public release was performed.

Local launch setup: this Mac’s already-running ChatGPT host passed the native opening check. If no existing companion target is configured, the local copy is preconfigured to that verified host; an existing target selection is preserved. New/unconfigured copies still provide the app chooser.
