# Aperture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a local macOS companion with a distinctive GSAP opening, a bounded interactive tab, and a small control deck around the selected Codex desktop host.

**Architecture:** Swift/AppKit owns application opening, native windows, focus, preferences, and lifecycle. Bundled HTML/CSS/SVG and GSAP own the original six-vane artwork and animation. A constrained native/web bridge carries UI commands; no target-app files or inner UI are modified.

**Tech Stack:** Swift 6 language mode, Swift Package Manager, AppKit, WebKit, plain HTML/CSS/JavaScript, locally bundled GSAP 3.13.0 core. Use Node's built-in tooling only where a packaging check needs it; no frontend framework or additional runtime dependency.

**Spec:** [Aperture design](../specs/2026-10-25-aperture-design.md). Read the complete spec and root GLOSSARY.md before implementing.

## Global Constraints

- macOS 14+ is the chosen deployment baseline; no Windows scope for v1.
- Fully offline at runtime; bundle GSAP and all artwork locally.
- No modifications to the target application's files, signatures, preferences, or conversation data.
- No Accessibility, Screen Recording, Automation, global key monitoring, or private APIs in v1.
- Only companion panel rectangles may consume input. Hidden panels are ordered out.
- Full sequence: at most 1,800ms after the web renderer is ready. Native watchdog dismisses a stalled stage at 2,500ms after presentation.
- Target already running: 450ms compact opening.
- Reduced motion: static mark, at most 120ms fade; quiet mode suppresses decorative motion entirely.
- No sound, synthetic task activity, automatic login startup, global shortcut, or remote assets.
- Plans and art direction are proposed; this document does not authorize implementation or installation.

## Review Focus

- Slow/failed JavaScript must not block target launch or leave a panel intercepting clicks; test in Task 1 and native gate in Task 5.
- Duplicate launch requests and late callbacks must not create extra windows or reactivate an app after dismissal; test in Task 1.
- Changing displays or switching Spaces must not strand a panel offscreen or above another app; geometry test in Task 1, native checks in Task 5.
- Combined ChatGPT/Codex host activation cannot identify the inner section; assert app-only matching in Task 1 and document/test actual behavior in Task 5.
- Rapid interaction and a live reduced-motion change must settle cleanly without stale hit targets or ongoing animation; browser self-checks in Task 2, native checks in Task 5.

## Task 1: Prove native opening and safe panel lifetime

**Files:** Create `Package.swift`, `main.swift`, `AppDelegate.swift`, `TargetApp.swift`, `LaunchSession.swift`, `CompanionController.swift` and the first three Swift test files listed above. Also create the minimal packaging script/plist needed to run a real app bundle; Task 4 finishes packaging, not a second build system.

**Interfaces:**

- `struct TargetApp: Equatable` contains `bundleIdentifier: String` and `url: URL`; `static func validated(at url: URL) throws -> TargetApp`; `func resolveURL() throws -> URL` prefers the installed bundle identifier and validates identity before using the stored path.
- `@MainActor func openTarget(_ target: TargetApp) async throws -> NSRunningApplication` uses NSWorkspace, never a shell. It opens with `NSWorkspace.OpenConfiguration.activates = false`; the controller activates only on successful native completion while the spec’s foreground-intent guard still holds. Never activate from an animation callback.
- `struct LaunchSession` exposes `begin(isRunning: Bool) -> UUID?`, `finish(id: UUID, succeeded: Bool)`, `dismiss()`, `expireStage()`, `expireRequest()`, and readable `requestID: UUID?`, `stageVisible: Bool`, `status: Status`, `compact: Bool`. `Status` is `idle | opening | opened | failed | timedOut`. An in-flight `begin` returns nil. Dismissal is independent of request outcome. Expiration invalidates callbacks from the expired generation.
- `@MainActor final class CompanionController` exposes `launch(_ target: TargetApp)`, `dismissStartup()`, `showTab()`, `showDeck()`, `hideAll()`, `dispose()`. Native placeholder content is sufficient for this gate.
- `static func stageFrame(in visibleFrame: CGRect) -> CGRect` fits 720 × 440pt with 20pt margins; `static func tabFrame(in visibleFrame: CGRect) -> CGRect` fits 64 × 48pt at top-right with 20pt margins. Tiny/invalid frames hide surfaces rather than produce negative geometry.

Assert the state/interface values above, plus no more than one open request for duplicate begins. Use temporary fixture bundles; unit tests must not open real user apps.
- [ ] **Run red.** `swift test`; expect missing types/methods, not an unrelated compiler setup failure.
- [ ] **Implement the minimal host and lifecycle.** Use nonactivating NSWorkspace open completion, the guarded foreground-intent rule and its own notification center, native app chooser, native Escape handling, monotonic 2.5s/10s deadlines with generation checks, and a bounded nonactivating panel for the tab. Provide an accessible native menu with Open App, Choose Target App, Show/Hide Companion, Quiet Mode, and Quit. First setup only offers the detected ChatGPT candidate; the user chooses it explicitly. No persisted target should be selected invisibly.
- [ ] **Run green.** `swift test`; all named tests pass. Run `bash scripts/build-app.sh` and open `dist/Aperture.app`; do not install it into Applications.

## Task 2: Build the signature artwork and deterministic motion

**Files:** Create the four bundled Web files and `Tests/Web/motion.html`, `Tests/Web/motion-checks.js`.

**Interfaces:**

- `window.Aperture.present({surface, reducedMotion, quiet, compact})`, `dismiss()`, `dispose()`, `setLaunchStatus(status)` as fixed by the spec. Present replaces prior animation and resets visibility and focusability.
- `window.Aperture.createStartupTimeline({compact, reducedMotion, quiet})` returns a paused GSAP timeline with labels `resolve`, `open`, `close`, `handoff`; duration 1.8s normally, 0.45s compact, ≤0.12s reduced motion, zero decorative motion in quiet mode. This same factory is used in production and the real-browser tests.
- CSS media query and native reducedMotion input are ORed; a media-query change tears down and reapplies the current surface without replaying the ritual or emitting a new launch request.
- The web self-check exposes `window.apertureTestResults = {passed, failed, failures}` and a visible text report. Tests load the actual production scripts and SVG, with a minimal fake native message sink only.

- [ ] **Write real-browser failing assertions.** Verify six vane groups; normal/compact/reduced timeline durations; required label ordering; readable opening status; `dismiss()` making all web controls hidden/nonfocusable; `dispose()` leaving no owned active tween; repeated `present()` leaving one surface; changing reduced motion mid-opening removing vane transforms; quiet presentation not running decorative tweens. Seeking the real timeline to start, open, and end must produce distinct expected vane transforms and a settled endpoint.
- [ ] **Run red in a browser.** Serve the project locally using `python3 -m http.server 4173 --bind 127.0.0.1`, open `/Tests/Web/motion.html`, and inspect the visible report plus `window.apertureTestResults`. Expect assertion failures for absent implementation. This development server is not part of the delivered app.
- [ ] **Implement original SVG and motion.** Vendor `https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/gsap.min.js`, preserve license text and record the artifact hash in README. Use classic local scripts. Apply the spec's exact tokens, score, size bounds, rotation limits, and easing choices: `power3.out` for separation, `power2.inOut` for coupled vane movement, `power2.out` for settling. Use timeline labels/positions; no chained delay callbacks, glow filters, backdrop blur, or layout-property animation.
- [ ] **Run green and visually review.** All self-check assertions pass. Inspect actual opening at 0ms, 650ms, 1,180ms, and 1,800ms, compact and reduced variants; no clipping, overshoot, flicker, unreadable label, or unintended empty frame. Reject both a generic camera/shutter illustration and a dense sci-fi HUD; the target is technical identity at a glance without visual aggression. ## Task 3: Integrate tab, deck, and truthful app lifecycle

**Interfaces:**

- Bridge accepts exactly a main-frame bundled-page message `{action}` using the allowlist in the spec. Define `static func validatedAction(body: Any, isMainFrame: Bool, sourceURL: URL?, bundledPageURL: URL) -> String?`; return nil for any unexpected key/type/action/origin.
